# penhold-media

Öffentliche Ablage für Bilder und Videos geplanter Penhold-Posts (`p/<post-id>/…`), ausgeliefert über
GitHub Pages unter `https://media.penhold.app`. Instagram und TikTok holen die Medien zur Sendezeit von hier.
Befüllt und aufgeräumt wird das Repo von `penhold-content` (`npm run publish`), nie von Hand.
